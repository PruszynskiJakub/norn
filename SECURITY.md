# Security policy

norn acts on GitHub with your own `gh` credentials and runs git and agent commands on your machine, so security problems matter even in a small tool.

## Supported versions

Only the latest release gets security fixes while norn is pre-1.0.

## Reporting a vulnerability

Please do not open a public issue. Email **jakub.mikolaj.pruszynski@gmail.com** with:

- what the problem is and what an attacker could do with it;
- the steps to reproduce it, and the norn version (`package.json` or the release tag);
- any fix you have in mind.

You will get a reply within a week. Once a fix is released, the changelog credits you, unless you would rather not be named.
